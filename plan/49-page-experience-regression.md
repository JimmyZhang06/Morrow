## 主线页的功能边界

材料数量与状态由程序计算，不由模型编造。仅把当前有效、有依据且经用户认可或纠正的认识计为可整理材料。暂缓判断计入待处理。已认可但依据失效的材料引导回认识核对。

主线仍是模型根据材料提出的解释。页面把解释和依据并排展示，不把它改写成人格结论。当前认识版本变化时提示重新整理；同分钟生成的多个版本用“第 N 版”区分。未被引用的认识只提示未引用，不宣称模型忽略或已经掌握了全部人生。

“查看已认可材料”和“核对与修正”直接进入认识页的已认可筛选；待判断入口进入待判断筛选，避免按钮带到空列表。缺失引用会给出明确查找入口。

## 验证方式

使用独立 Electron 配置目录、真实本地 API 和数据库，模型层使用固定的合成回包，未读取或修改用户的真实记录与模型配置。本轮测试检验布局、状态和业务连接，不作为真实模型输出质量评估。

- TypeScript / Vite 构建。
- 空页与有数据页面截图；1380 × 860 和 980 × 660 窗口回归。
- 今天草稿追加，认识/尝试空态导航。
- 保存记录 → 生成认识 → 查看依据 → 用户认可 → 生成尝试。
- 主线生成 → 再生成 → 版本下拉 → 查看已认可材料 → 生成章节。
- 自定义日期弹层 → 保存日历候选 → 确认 → 撤销，没有导入系统日历。
- 新建对话草稿衔接、发送并显示回答。
- 主线空态、待判断、可生成、AI 不可用、材料更新和引用缺失状态测试。
- 聊天流式回归：逐步显示、停止、截断保留、刷新恢复、流末尾处理、携带未完内容继续对话。

以上流程与构建均已通过。新增的跳页修复在最终全流程版本中通过复测。
