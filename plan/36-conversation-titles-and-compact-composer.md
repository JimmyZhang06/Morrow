# 紧凑输入区与持久会话名称

2026-09-11。

输入区默认约两行，随内容增高至 96px，之后在框内滚动。回信模式与自动检索选项放进“选项”菜单，保留发送按钮，减少固定占用的高度。

列表 API 直接返回名称，前端不再依赖打开会话后填充的临时名称缓存。旧会话使用第一条可用提问作为名称。AI 在正常回复的同一次请求中额外生成简短主题名，不单独发起收费请求；后续回复可更新主题名。供应商未返回名称时沿用提问摘要，不影响正文。

AI 名称与回复一同加密保存，引用、授权或认识变化导致回复失效时，列表也不展示该回复的派生名称。手动名称独立加密存储于会话记录，优先于 AI；无需启用在线模型即可重命名。删除对话会清除手动名称。迁移 `56ef78ab90cd` 为既有数据库添加手动名称与版本字段。

标题旁的编辑按钮支持 1–60 字名称，保存后列表立即同步；Enter 保存、Escape 取消。接口检查名称版本，避免不同窗口的过时保存覆盖新名称；失败时保留输入。列表每五秒刷新一次，当前会话的流式轮次仍每 350ms 拉取。

单元测试覆盖首次列表名称、AI 标题、加密、手动名称重载、冲突、跨 Vault、删除及来源失效。桌面回归覆盖不打开会话即显示标题、手动重命名后刷新、继续对话不覆盖手动名称，以及默认输入区高度和多行上限。

64 项相关单元测试通过。实际 Electron 桌面回归和 PostgreSQL 升降级迁移、RLS、备份恢复与重启验证通过；150% 缩放截图位于 `.data/release-evidence/conversations/chat-150.png`。可运行版本位于 `apps/desktop/release-chat-titles/win-unpacked`。
