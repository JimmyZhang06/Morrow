# Vistora Desktop v0.3 视觉精修评审

日期：2026-08-24  
目标：在不增加认知负担的前提下，让桌面端从“结构正确”进入“可长期使用的精致产品”阶段。

## 1. 本轮发现

v0.2 已完成输入优先的信息架构和真实后端能力边界，但实际渲染后仍有六类问题：

1. **可读性不足**：辅助文字大量低于 10px，暖灰配色下对比度进一步下降。
2. **细节一致性不足**：记录元信息粘连、侧栏服务状态拥挤、设置导航缺少当前态。
3. **关键图标没有行为**：顶部隐私锁看起来可点击，却不能快速切换遮罩。
4. **页面状态偏工程化**：设置页像诊断面板，空状态只表达“没有”，缺少下一步引导。
5. **触感不足**：按钮、列表、卡片的 hover / pressed / focus 节奏不完全一致。
6. **层级偏平**：同一页面里的标题、说明、状态和正文缺少更细腻的明暗、间距与表面层次。

## 2. v0.3 精修原则

- 最小正文不低于 11px，关键说明维持 12–13px；极少数标签可使用 10px。
- 提升辅助文字对比度，但避免纯黑和高饱和色。
- 交互元素必须有 hover、pressed、focus-visible 和 disabled 四种反馈。
- 空状态同时回答：当前是什么、为什么、下一步可以做什么。
- 设置页区分“日常设置”和“开发诊断”，技术名词降级为次要信息。
- 视觉装饰不制造虚假功能；可点击外观必须对应真实行为。

## 3. 本轮实现范围

- 全局字体、颜色、圆角、阴影、滚动条和动效统一；
- 首页输入器、提示词、待处理条和最近记录精修；
- 记录列表元信息重排，改善扫描效率；
- 顶部隐私按钮接入真实遮罩，并显示激活状态；
- 侧栏当前页、服务状态与最近记录细节修复；
- 行动和认识空状态增加解释性结构；
- API 令牌增加显示/隐藏控制；
- 弹窗关闭按钮、表单控件与键盘焦点统一；
- 1440×900、1100×760 两档桌面窗口视觉回归。

## 4. 不采用的“精致化”方式

- 不加入玻璃拟态、重渐变、动态粒子或大面积品牌色；
- 不复制 Claude 的品牌图形、字体或专属颜色；
- 不用动画掩盖等待，也不把后端不可用包装成成功；
- 不为了填满空白而生成假洞察、假行动或人格标签。

## 5. 验收标准

- 记录列表时间、整理状态和同步状态不粘连；
- 隐私遮罩可从顶部一键开启和关闭；
- 所有核心文字在 100% Windows 缩放下可读；
- 侧栏、主页面、弹窗的圆角与控件高度形成统一规格；
- 两档桌面尺寸无横向滚动、遮挡或错误折行；
- 控制台无运行时错误，TypeScript、Vite 构建和后端契约测试通过。
