# 应用内日期与下拉组件

新增 `Picker.tsx` 和 `Picker.css`，使用 React 编写弹层、月份网格、时间输入和选项列表，统一宣纸色、墨灰边框与阴影。

替换范围：
- 外部日历候选的开始和结束时间。
- 小尝试编辑器中的预计用时。
- 关怀来信的展示方式。

交互：日期与时间先在弹层内编辑，点击确定才写入；支持方向键日期跨月、下拉框上下键和首尾键、回车选择、Escape 取消并返回触发按钮、点击或聚焦外部关闭。弹层通过 portal 渲染，根据窗口边缘定位，避免被容器裁切。小时和分钟有范围校验，月份长度由本地日期运算确定。

源代码扫描已无原生 select、datalist 和日期/时间 input。外部日历的导出业务及数据授权逻辑不变。

TypeScript 与 Vite 构建通过。交付目录：`apps/desktop/release-custom-pickers/win-unpacked/`。

组件在构建后的 Electron 页面中验证通过：键盘选择、2028 年 2 月 29 日、方向键跨月、无效时间不能确认、取消不改值、焦点返回、点击外部关闭。截图保存在 `.data/release-evidence/pickers/`。
