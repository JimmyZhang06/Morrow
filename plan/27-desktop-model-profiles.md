# 桌面多模型配置

版本：0.6.0-beta.2，2026-09-10。替代 beta.1 的单一 Step Plan 限制。

- 设置页保存至多 20 个配置，独立名称、HTTPS Base URL、模型 ID、API Key 和可选 JSON 模式。
- 通用协议为 Chat Completions，保留 Step Plan 专用适配器。其他原生协议未实现，不能宣称所有模型服务均兼容。
- 密钥只存于 Windows safeStorage 保护的主进程配置，不通过状态 IPC 返回；不进入备份。地址或协议变化禁止自动复用旧密钥。
- 每次主动启用或切换生成独立同意交互，保留撤回后的默认拒绝语义。通用供应商处理地区记为 unspecified，保留和训练按最保守的供应商管理方式授权，不作地理或零保留承诺。
- 模型运行版本绑定端点与 JSON 模式摘要；切换时取消尚未完成的旧后台任务，避免旧请求在新供应商重放。
- HTTPS 请求不跟随重定向，错误只保留安全原因码。默认发送 model/messages/stream，JSON 模式由用户选择；继续使用已有结构、证据校验和确认流程。
- 旧配置自动呈现为 Step Plan 配置。关闭 AI 删除当前密钥，其他配置保留；恢复备份清除所有模型密钥并关闭 AI。

验证：Python 回归、类型检查、HTTP 模拟的最小请求/重定向拒绝/响应验证、Node 配置切换和密钥隔离、真实 PostgreSQL 迁移/RLS 与备份恢复、模拟模型 HTTP 的候选→证据→确认→行动→撤销流程，以及实际打包 Electron 的两配置切换和重启持久化。

实际供应商成功调用仍需要用户提供有效服务配置与额度；模拟验证不等于真实模型质量验收。试用包未商业签名，仍需独立干净 Windows 机器的安装升级验收。

## beta.3 配置列表优化

以卡片列表替代原生模型下拉菜单，独立新增按钮，区分编辑选中与实际使用中。首次启动不预置模型配置；保留已有用户配置。删除非当前配置仅更新加密设置，不重启服务；删除当前配置关闭 AI 并移除对应密钥。

## beta.4 新版本默认空白

根据用户要求，打包版本在 Electron ready 之前同时将 userData 和 sessionData 定位到 versions/<版本号>，不读取旧版数据库、localStorage 或模型密钥，也不自动导入旧版 JSON。旧文件保留作回退；同版本重启沿用本版本数据。恢复备份是用户主动迁移的入口。发行测试预置旧目录历史，确认新版本仍为空，并检查浏览器存储实际位于新目录。
