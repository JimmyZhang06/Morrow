# 会话历史连续性

同一会话按顺序提供全部已保存的用户消息、仍有效的完整 AI 回复，以及历史回复使用的日记原文。检索词、命中日记、回信模式发生变化，不再导致此前 AI 回复被省略。关闭应用后重新打开同一会话，仍从加密存储恢复历史。

提示词要求结合前文理解人物、时间、偏好、约定和指代；用户后续纠正优先于先前说法，不重复询问已知信息。AI 旧回复用于延续讨论，不能作为用户事实的证据。

历史回复逐轮重验授权与已审核记忆；记录回复对先前有效回复的依赖。当早期依据撤回或纠正，依赖该回复的后续内容也停止进入模型上下文。旧版本保存的回复继续兼容。

每会话最多 100 轮，完整上下文预算 120000 字符，输入引用总数最多 256（含额外记忆引用）。模型自身容量仍有上限。发送事务内检查预算，超限返回明确错误并回滚，不静默截断历史。模型网关仅为 conversation_reply 放宽原 32 片段限制，其他任务保持原限制。

此变更针对同一会话，不自动把其他会话混入当前聊天，也不增加跨会话个人画像。

验证：应用与 AI 测试 454 项通过；Ruff 与 mypy 通过；前端构建通过。新增回归覆盖检索/回信模式切换、35 轮历史和用户纠正、超过 32 片段、上下文超限回滚、撤回依据后的依赖失效。桌面会话流程、增量流式输出/取消/中断、实际 EXE 启动与本地 API 冒烟验证均通过。可运行版本：apps/desktop/release-chat-memory/win-unpacked/Morrow.exe。
