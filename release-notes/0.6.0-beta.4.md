# Vistora 0.6.0-beta.4 试用说明

这是面向少量受邀用户的 Windows x64 试用版本。应用和数据服务在本机运行，无需安装 Python、Docker 或 PostgreSQL。

## 新版默认空白

每个新版本首次启动使用独立的空白数据空间，不自动载入旧版记录、草稿、认识、行动或模型配置。同一版本后续启动会保留本版本新写的记录。旧目录保留但不自动显示，若需迁移，请在旧版导出加密备份后主动恢复。重新下载或重新安装同一版本不会清空它已保存的新记录。

## 开始使用

1. 启动安装版或便携版；首次建立私人空间需要稍等。
2. 直接写下记录。没有网络或未配置 AI 时仍可保存。
3. 如需 AI，在“设置与隐私”新增模型配置，填写名称、HTTPS API 根地址、API Key 和模型名称，确认数据处理说明后点击“保存并切换到此模型”。可保存多个配置，选择后再次点击即可切换。支持 OpenAI 兼容 Chat Completions API；原生 Anthropic / Gemini 等其他协议需使用兼容接口。Step Plan 可选择专用协议。JSON 模式仅在供应商支持时开启。
4. 从已保存的记录请求整理，查看候选认识的原话依据，再确认、修正或拒绝。
5. 选择认可的认识生成小行动，接受、完成或撤销。“完成”只是状态标记，当前没有专门的复盘编辑器。

切换配置会取消之前未完成的后台任务，避免转发到新供应商。地址变更后须重新输入密钥；密钥不显示在界面。关闭 AI 移除当前配置密钥，其他已保存配置保留。配置成功仅表示设置生效，不能证明账户有额度或模型可用。

## 隐私与备份

- 供应商的数据处理地区、保留期限与训练规则适用，通用接口不承诺零保留或禁止训练。
- 在线 AI 会把所选记录及必要的相关材料发送到模型供应商，费用由你的模型账户承担。应用不是完全离线 AI，也不是诊断或治疗工具。
- 模型 Key 和本机数据密钥由 Windows 当前账户加密保护。不要只复制数据库目录到其他账户，应使用应用内的加密备份。
- 定期在设置中导出 `.vistora` 备份，密码至少 12 个字符。密码无法找回，请与备份文件分开保管。
- 备份包含记录、认识、行动和本机草稿，不包含在线模型 Key。恢复后在线 AI 默认关闭，需要重新配置。
- 原数据库、旧版原始文件和用户导出的备份可能保留已删除记录。删除单条记录不会清除这些保留副本。
- 本机草稿和部分派生数据没有全盘加密；建议为 Windows 账户设置密码，并使用设备加密。

## 升级、故障与反馈

- 升级前先导出备份。安装和卸载不会主动删除应用数据。
- 安装版不再自动导入旧版 JSON 记录。旧目录保留，可通过旧版导出备份后主动迁移。
- AI 失败不代表记录丢失。若提示结果无法确认，先检查原任务，不要连续重复请求。
- 订阅未激活、Key 失效、额度不足时，请检查供应商账户。
- 这是未进行商业代码签名的试用包，Windows 可能显示发布者或信誉提示。只使用邀请者提供、且校验值匹配的文件；不确定时可以取消安装。
- 反馈请联系邀请你试用的人，提供版本、操作步骤和不含正文的错误提示，不发送 API Key、数据库或完整日记。

当前没有自动更新、多设备同步、整本回忆录导出或第三方日历直接写入。日历确认只允许导出 ICS 文件。

模型配置使用卡片列表，独立新增按钮，标明使用中的模型；支持删除配置及其密钥，删除当前配置会关闭 AI。首次启动不预置模型配置或测试记录。
